[ UPGRADE STEPS ]
1. Power off the device and disconnect the power supply.
2. Press and hold the OK button, then connect the device to a Windows computer using a USB Type-C data cable. The device will enter Bootloader Mode.
3. The computer will recognize the device as a USB drive named BOOTLOADER.
4. Copy the firmware BIN file directly to the root directory of the BOOTLOADER drive.
5. The device will automatically complete the upgrade and restart.
6. After the upgrade, reconnect the device to a power supply and check the firmware version in the menu.

Note: Make sure to press and hold the OK button before connecting the USB cable.
